# Data

`sample/211048.json` is one match file from [Cricsheet](https://cricsheet.org), in Cricsheet's JSON format (data version 1.0.0). It covers the first men's T20 international: New Zealand v Australia at Eden Park, Auckland, 17 February 2005.

It is included so you can inspect the structure and test the pipeline end to end. To load more matches, download any JSON archive from <https://cricsheet.org/downloads/> and upload the files to the S3 prefix the pipeline watches.
